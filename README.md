# PromoG3L

PromoG3L is a promoter sequence generation and optimization framework for *Escherichia coli* and *Streptomyces coelicolor*. It combines fine-tuning of a generative genomic language model with reinforcement learning to generate and optimize promoter sequences with high predicted activity for the target species.

## Framework Overview

```text
GENERator base model
        │
        ▼
LoRA fine-tuning on promoter data
        │
        ▼
PPO policy optimization ◄──────── Promoter activity predictor
        ▲                         ├─ E. coli: CNN-LSTM regressor
        │                         └─ S. coelicolor: ProkBERT-CNN regressor
        │
        └──────────────────────── TFBS similarity reward + nucleotide-type reward
        │
        ▼
Optimized promoter sequence generation
```

During PPO optimization, the reward combines predicted promoter activity, similarity to the TFBS distribution of natural promoters, and nucleotide-type constraints.

## Installation

Python 3.10 or 3.11 is recommended. A CUDA-enabled GPU is recommended for LoRA fine-tuning and reinforcement learning.

```bash
git clone https://github.com/OneCxy/PromoG3L.git
cd PromoG3L

conda create -n promog3l python=3.10
conda activate promog3l
pip install -r requirements.txt
```

For GPU acceleration, install the PyTorch build that matches the local CUDA version.

## Model Preparation

### GENERator

Obtain the prokaryotic GENERator model from the [official GENERator repository](https://github.com/GenerTeam/GENERator), and then edit:

```text
src/tasks/Fine_tuning/fine_tuning_lora_config.json
```

The `model_name` field can be set to a Hugging Face model identifier:

```json
"model_name": "GenerTeam/GENERator-v2-prokaryote-1.2b-base"
```

Alternatively, it can point to a downloaded local model directory:

```json
"model_name": "path/to/GENERator-v2-prokaryote-1.2b-base"
```

### ProkBERT

Obtain ProkBERT from the [official ProkBERT repository](https://github.com/nbrg-ppcu/prokbert). This project uses `prokbert-mini`.

Edit:

```text
src/tasks/RL/expression_reward/Sco_predictor/predictor_train_config.json
```

## Data Preparation

### Fine-tuning Data

Prepare the data in `datasets` according to the target species. For *E. coli*, construct the three-level fine-tuning dataset as required. For *S. coelicolor*, the corresponding promoter sequences can be used directly. Split the resulting data into training and validation sets.

The training and validation sets must be CSV files containing a promoter sequence column.

Set the data, model, and output paths in `fine_tuning_lora_config.json` before the first-stage fine-tuning.

### Activity Prediction Data

The CSV file used to train the activity predictor must contain DNA sequences and numerical activity labels:

```csv
sequence,activity
ATGCGTACGTAGCTAGCTAG,1.25
TTGACATATAGCGCGTATGC,-0.31
```

### TFBS Data

The TFBS reward requires:

- a target-species motif file in MEME format;
- natural high-activity promoter sequences for constructing the reference distribution; and
- a natural high-activity promoter TFBS reference vector generated by `nature_tfbs.py`.

## Workflow

### 1. Fine-tune GENERator with LoRA

First edit `src/tasks/Fine_tuning/fine_tuning_lora_config.json`, and then run:

```bash
python src/tasks/Fine_tuning/fine_tuning_local_LoRa.py
```

The fine-tuned or merged model is written to the configured `output_dir`.

### 2. Prepare the Promoter Activity Predictor

#### E. coli Activity Predictor

The *E. coli* branch uses a CNN-LSTM regression model:

```bash
python src/tasks/RL/expression_reward/Ecoli_predictor/predictor_train.py
```

#### S. coelicolor Activity Predictor

The *S. coelicolor* branch uses a ProkBERT encoder with a multi-kernel CNN regression head. Edit `predictor_train_config.json`, and then run:

```bash
python src/tasks/RL/expression_reward/Sco_predictor/predictor_train.py
```

The trained predictor directory must contain the model weights, model metadata, tokenizer files, and label statistics.

### 3. Construct the Natural High-Activity Promoter TFBS Reference Vector

Select high-activity promoters from the target species and prepare a CSV file containing the sequences and their activity values.

Edit `src/tasks/RL/tfbs_reward/nature_tfbs_config.json`, and then run:

```bash
python src/tasks/RL/tfbs_reward/nature_tfbs.py
```

This script scans natural promoter sequences using the MEME motif file and generates the TFBS reference vector required for reinforcement learning.

### 4. Run PPO Reinforcement Learning

Select the organism-specific workflow:

```bash
# E. coli
python src/tasks/RL/Ecoli_RLpro.py

# S. coelicolor
python src/tasks/RL/Sco_RLpro.py
```

Before running the selected RL script, configure:

- the policy model directory produced by LoRA fine-tuning;
- the activity predictor model or checkpoint path;
- the MEME motif file;
- the natural high-activity promoter TFBS reference vector; and
- the RL output directory.

The best-performing policy model is saved in the `ppo_best` directory under the configured output directory.

### 5. Generate Optimized Promoter Sequences

Edit `src/tasks/Generation/generate_seed_config.json` and set `model_dir` to the LoRA-fine-tuned model or the PPO-optimized `ppo_best` model directory. Then run:

```bash
python src/tasks/Generation/generate_seed.py
```

The generated sequences and run information are saved to the configured `outdir`.

## Standalone Activity Prediction

### E. coli

The input CSV file must contain a `sequence` column:

```bash
python src/tasks/RL/expression_reward/Ecoli_predictor/predictor_activity.py \
  --ckpt src/tasks/RL/expression_reward/Ecoli_predictor/LSTMModel.pth \
  --in_csv path/to/sequences.csv \
  --out_csv outputs/ecoli_activity_predictions.csv
```

The script also supports TXT input with one sequence per line.

### S. coelicolor

Edit `src/tasks/RL/expression_reward/Sco_predictor/sco_predictor_config.json`, and then run:

```bash
python src/tasks/RL/expression_reward/Sco_predictor/sco_predictor.py
```

The input CSV file must contain a promoter sequence column. The script appends the predicted activity values to the output CSV file.

## Bioinformatics Analysis

The `bio_analysis` directory contains the following downstream analysis scripts:

- `bio_analysis/GC_violin.py`: compares GC-content distributions among natural, generated, and random sequences and produces violin plots;
- `bio_analysis/kmer_multi_analysis.py`: calculates and compares k-mer frequencies and correlations across sequence sets;
- `bio_analysis/editdistance.py`: calculates edit distances between sequence sets and plots their distributions;
- `bio_analysis/DNA_shape.py`: reads Roll, MGW, HelT, and ProT data and compares DNA-shape features across sequence sets;
- `bio_analysis/motif_seqlog.py`: generates sequence logos from motif or sequence data.
